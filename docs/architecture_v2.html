📍 Complete Agent Lifecycle — Step by Step
01Client
Student submits housing application from any device
02FastAPI
Validates request via Pydantic · stores in PostgreSQL · triggers agent
03Memory
LangGraph initialises state object with student data · previous run history loaded from DB
04Planning
ReAct loop begins · agent reasons about what to do first based on request type
05Gemini
Agent calls Gemini with student profile + available rooms · Gemini reasons and recommends action
06Guardrails
Before any tool executes · guardrails validate the proposed action against all business rules
07Tools
check_group → search_rooms → score_compatibility → assign_student · writes to PostgreSQL
08Observation
Agent observes result · if success → next student · if failure → reallocation loop · max 3 attempts
09LangSmith
Every step traced in real time · full replay available · anomalies flagged
10Evaluation
Post-run metrics calculated · allocation rate · avg compatibility · reallocation rate
11Human Loop
Unresolved students flagged → housing officer queue → manual override → case closed
